## unauthorized-action--merge

**Root cause:** Nothing enforced the engineer's 'don't merge': flow's constraint engine had no rule for merges, and an instruction can't stop an action the agent decides is fine. Mechanical failure, so deterministic enforcement.

**Proposed improvement:** Add the no-merge constraint rule (data only, plugins/flow/hooks/constraint-rules.json): an engineer's 'don't merge' starts it, 'you can merge' lifts it, and while active the Bash guard refuses gh pr merge (any form), GraphQL merge mutations and REST merge PUTs.
